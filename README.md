## 🚀 Featured Projects

### 🌾 FarmFloodAid — AI-Powered Disaster Assistance

**Building technology for communities that need it most.**

A disaster assistance platform designed to help flood-affected farmers access essential resources and support.

- 🤖 AI-powered chatbot for assistance and information.
- 🌱 Crop marketplace connecting farmers with potential buyers.
- 🤝 NGO directory for aid and resource coordination.
- 🗄️ MongoDB, Redis, Supabase and REST API integration.
- 🏆 Winner — Myanmar Flood Hackathon Community Impact Award.

### 🌱 SurplusX — Smart Food Surplus Management

**Turning surplus into opportunity.**

A smart resource-sharing platform focused on reducing food waste by connecting restaurants and NGOs.

- 📊 Role-based dashboards for restaurants, NGOs, and administrators.
- 🔐 JWT-based authentication and access control.
- ⚡ Smart allocation algorithm for efficient surplus distribution.
- 🧩 Full-stack development using React, Node.js, Express and MongoDB.
